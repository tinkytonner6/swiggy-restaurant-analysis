# Swiggy Restaurant Analysis 🍽️

Exploratory Data Analysis and ML model on Swiggy Bangalore restaurants.

## 📊 Project Overview
This project analyzes Swiggy restaurant data across India with a deep dive into Bangalore's food scene.

## 🔍 Key Insights
- Jayanagar is Bangalore's most restaurant-dense area
- Chinese cuisine dominates Bangalore's food scene
- Mid-range restaurants (₹150-₹300) have the highest ratings
- Bangalore has 57% Pure Veg restaurants vs 42% Non-Veg
- Hidden gems with 5.0 ratings exist at under ₹300
- ML model predicted high-rated restaurants with 67% accuracy

## 🛠️ Tools Used
Python, Pandas, Numpy, Matplotlib, Seaborn, Scikit-learn
